# Клоп·Новости 🐞

Персональный видеовыпуск новостей для семьи. Ведущий — Клоп Александрович, на главных сюжетах — прямые
включения корреспондентки Клопика (розовый бантик). Каждый выбирает свои темы, источники и длительность;
утром бот присылает в Telegram ссылку на выпуск на сайте `news.sorpredente.com` — им удобно делиться.

```
RSS 17 источников ─► editor: модель отбирает события за сутки, склеивает дубли, пишет сюжеты по полным текстам
Yahoo Finance ─────► блок «Рынки»: цифры из котировок, модель только комментирует
Афиши + Brave ─────► блок «ИИ в Праге»: митапы и лекции на неделю (как «Встречи» в piano-piano)
                      │
                      ▼  один раз на всех
               producer: озвучка (gpt-4o-mini-tts) + студия (Pillow + ffmpeg) → клип на каждый сюжет
                      │
                      ▼  под каждого
               склейка: личное интро «Привет, Маша!» + сюжеты по настройкам + финал → mp4 без перекодирования
                      │
          Telegram «выпуск готов» ──► сайт: плеер, главы, ссылки на источники, «Поделиться», настройки
```

## Почему так

- **Сюжет рендерится один раз, выпуск — склейка.** Стоимость растёт от числа новостей, а не людей.
  Личное только интро (~15 с).
- **10 минут набираются.** На день — до 8 событий по каждой из 5 тем: главные (~1 мин, по полному тексту статьи,
  с «почему это важно» и мнением Клопа) и «коротко» (~20 с). Если выбрал 1–2 темы, выпуск честно короче.
- **Голос** — OpenAI `gpt-4o-mini-tts`, как в piano-piano: характер задаётся текстом
  («тёплый баритон с иронией»), ~$0.015/мин. Провайдер меняется в `.env` (любой OpenAI-совместимый API).
- **Клопик** — 2D-персонаж поверх настоящего фото из статьи с подписью источника. Видео «с места событий»
  не генерируем: это выдуманные кадры реальных событий.
- **ИИ в Праге.** Раз в день перед сюжетами читаем афиши (AI Tinkerers, Luma) и поиск Brave (`BRAVE_API_KEY`, тот же, что
  в piano-piano): модель вытаскивает митапы, лекции и хакатоны на две недели вперёд. В выпуск — блок на неделю, когда нашлось
  новое, и по понедельникам обзор; только у кого включена тема ИИ. Ссылки на события — под видео.
- **Модель не придумывает факты:** пишет только по присланным текстам, цифры рынков берёт из котировок,
  о трагедиях — без шуток.

## Сколько стоит (семья, 5 человек)

| | в месяц |
|---|---|
| Озвучка: ~40 сюжетов × ~700 знаков в день | ~$12 |
| Модель (Kimi K2.6): отбор + ~40 сюжетов по полным текстам в день | ~$8 |
| Сервер, Cloudflare Tunnel | уже есть |

## Первый запуск на сервере

Ставится рядом с piano-piano, но отдельно: папка `/opt/klopnews`, порт 8095, свой туннель.

1. **Туннель Cloudflare.** Zero Trust → Networks → Tunnels → *Create a tunnel*, имя `klopnews`.
   Токен — в `.env`. *Public hostnames*: `news.sorpredente.com` → HTTP → `web:8000`. DNS Cloudflare пропишет сам.
2. **Бот.** @BotFather → `/newbot` (например, `KlopNewsBot`), токен — в `.env`. Telegram ID семьи
   (у @userinfobot) — в `ALLOWED_TELEGRAM_IDS`.
3. **`.env`:**
   ```bash
   cp .env.example .env   # ключи Kimi и OpenAI, SESSION_SECRET, токены
   ssh root@204.168.241.143 'mkdir -p /opt/klopnews' && scp .env root@204.168.241.143:/opt/klopnews/.env
   ```
4. **Деплой:** `./deploy.sh` вручную или merge в `main` (GitHub Actions; секреты `DEPLOY_SSH_KEY`,
   `DEPLOY_KNOWN_HOSTS` — те же, что у piano-piano).
5. Каждый из семьи пишет боту `/start` → получает ссылку на настройки. `/now` — собрать выпуск сразу.
6. **Админка.** Свой Telegram ID — в `ADMIN_TELEGRAM_IDS`, боту — `/admin`: придёт ссылка на `/admin` (кто подключён, открывают ли выпуски, сколько досматривают, где бросают, как собрались сюжеты дня).
   Плеер на странице выпуска раз в 10 с сообщает, докуда досмотрели; переход по ссылке из бота засчитывается адресату.

Ручные команды на сервере:
```bash
docker compose exec worker python -m klopnews.cli fetch        # собрать RSS
docker compose exec worker python -m klopnews.cli edition      # сюжеты дня
docker compose exec worker python -m klopnews.cli episode <tg_id>
```

## Разработка

```bash
pip install -e ".[dev]"     # нужен ffmpeg и шрифт Inter (apt install ffmpeg fonts-inter)
pytest -q                   # весь конвейер без сети: fake-модель, бип-озвучка

export DATA_DIR=./data LLM_PROVIDER=fake TTS_PROVIDER=dummy
python -m klopnews.cli demo && python -m klopnews.cli edition && python -m klopnews.cli episode 1
uvicorn klopnews.web:app --reload
```

## Где что

| | |
|---|---|
| `config/sources.yaml` | темы, RSS, котировки, афиши и запросы для «ИИ в Праге» |
| `klopnews/editor.py` | промпты: характер Клопа, правила, отбор и тексты |
| `klopnews/render/characters.py` | Клоп Александрович и Клопик, нарисованные кодом |
| `klopnews/render/studio.py` | студия, включение, рендер клипов |
| `klopnews/events.py` | сбор ИИ-ивентов в Праге: афиши, поиск, модель вытаскивает даты |
| `klopnews/producer.py` | клипы сюжетов, подбор под человека, склейка |
| `klopnews/worker.py`, `bot.py` | расписание и Telegram |
| `klopnews/web.py`, `templates/` | сайт |
