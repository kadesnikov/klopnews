# Брендинг бота

Картинки рисуются из тех же персонажей, что и в выпуске: `python branding/make.py`.

| Файл | Куда |
|---|---|
| `avatar.png` | аватар бота: @BotFather → `/setuserpic` → выбрать бота → прислать файл **как фото** |
| `avatar-klopik.png` | запасной аватар с Клопиком |
| `cover.png` | картинка над описанием («Что умеет этот бот?»): @BotFather → `/mybots` → бот → *Edit Bot* → *Edit Description Picture* |

Имя, короткое и длинное описание, меню команд бот выставляет себе сам при каждом запуске воркера
(`klopnews/bot.py`, `apply_branding`). Поменять тексты — поправить их там и задеплоить.
